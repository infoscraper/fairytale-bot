# Автоматическое исправление прав доступа - РЕШЕНО! ✅

## Проблема полностью решена!

Проблема с правами доступа (`EACCES: permission denied`) решена **автоматически** через несколько механизмов.

## Что настроено:

### 1. 🔄 Cron Job (ГЛАВНОЕ РЕШЕНИЕ)
**Автоматическое исправление прав каждую минуту:**
```bash
*/1 * * * * sudo chown -R danil:danil /etc/dokploy/applications/fairytalebot-bot-zpwqwc/code && sudo chmod -R u+rwX,go+rX ...
```

Это означает, что даже если Dokploy/Docker меняет права обратно на `root:root`, они **автоматически исправятся через минуту**.

### 2. 🔧 Git Hooks (перед коммитом и push)
- **`.git/hooks/pre-commit`** - исправляет права перед каждым коммитом
- **`.git/hooks/pre-push`** - исправляет права перед каждым push

### 3. 📝 Ручной скрипт (если нужно)
```bash
bash fix_permissions.sh
```

Или используйте alias:
```bash
fixperms
```

## Как это работает:

1. **Каждую минуту** - cron job автоматически исправляет права
2. **Перед каждым коммитом** - git hook исправляет права
3. **Перед каждым push** - git hook исправляет права
4. **Файлы всегда принадлежат пользователю `danil`** с правами на запись

## Если проблема повторится:

1. Подождите 1 минуту - cron job автоматически исправит
2. Или запустите: `fixperms`
3. Или выполните:
   ```bash
   sudo chown -R danil:danil /etc/dokploy/applications/fairytalebot-bot-zpwqwc/code
   sudo chmod -R u+rwX,go+rX /etc/dokploy/applications/fairytalebot-bot-zpwqwc/code
   ```

## Примечания:

- Cron job работает в фоне и исправляет права автоматически
- Git hooks остаются на сервере и работают автоматически
- Даже если Dokploy меняет права - они вернутся через минуту!

**Больше не нужно беспокоиться о правах доступа! 🎉**
