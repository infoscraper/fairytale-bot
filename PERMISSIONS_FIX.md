# Автоматическое исправление прав доступа

## Проблема решена! ✅

Проблема с правами доступа (`EACCES: permission denied`) теперь решена автоматически.

## Что было сделано:

### 1. Git Hooks (автоматически перед коммитом и push)
- **`.git/hooks/pre-commit`** - автоматически исправляет права перед каждым коммитом
- **`.git/hooks/pre-push`** - автоматически исправляет права перед каждым push

Эти hooks работают **автоматически** - вам ничего делать не нужно!

### 2. Ручной скрипт (если нужно)
Если всё же возникнет проблема, запустите:
```bash
bash fix_permissions.sh
```

### 3. VS Code настройки
Создан файл `.vscode/settings.json` для оптимизации работы с файлами.

## Как это работает:

1. **Перед каждым коммитом** - git hook автоматически исправляет права
2. **Перед каждым push** - git hook автоматически исправляет права
3. **Файлы всегда принадлежат пользователю `danil`** с правами на запись

## Если проблема повторится:

1. Запустите: `bash fix_permissions.sh`
2. Или выполните:
   ```bash
   sudo chown -R danil:danil /etc/dokploy/applications/fairytalebot-bot-zpwqwc/code
   sudo chmod -R u+rwX,go+rX /etc/dokploy/applications/fairytalebot-bot-zpwqwc/code
   ```

## Примечание:

Git hooks находятся в `.git/hooks/` и **НЕ коммитятся** в репозиторий (это нормально).
Они остаются на сервере и работают автоматически.
