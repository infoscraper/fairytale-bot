# 🔧 Исправление переменной окружения в Dokploy

## Проблема

Аудио генерируется медленно из-за маленького размера чанков. В логах видно:
```
📝 Splitting text into chunks (max_bytes=800)...
✅ Text split into 7 chunks
```

Это означает, что переменная окружения `GEMINI_TTS_MAX_BYTES_PER_CHUNK=800` переопределяет значение по умолчанию `4500` из кода.

## Решение

### Вариант 1: Изменить значение переменной в Dokploy (РЕКОМЕНДУЕТСЯ)

1. Зайдите в Dokploy
2. Откройте проект `fairytalebot-bot-zpwqwc`
3. Перейдите в настройки переменных окружения
4. Найдите переменную `GEMINI_TTS_MAX_BYTES_PER_CHUNK`
5. Измените значение с `800` на `4500`
6. Нажмите "Сохранить"
7. Сделайте **Rebuild** для сервиса **Celery Worker**

### Вариант 2: Удалить переменную окружения

1. Зайдите в Dokploy
2. Откройте проект `fairytalebot-bot-zpwqwc`
3. Перейдите в настройки переменных окружения
4. Найдите переменную `GEMINI_TTS_MAX_BYTES_PER_CHUNK`
5. **Удалите** эту переменную (или установите пустое значение)
6. Нажмите "Сохранить"
7. Сделайте **Rebuild** для сервиса **Celery Worker**

## Результат

После изменения переменной:
- ✅ Размер чанков увеличится с 800 до 4500 байт
- ✅ Количество чанков уменьшится с 7-8 до 1-2
- ✅ Время генерации сократится с ~3.5 минут до ~30-60 секунд

## Проверка

После rebuild проверьте логи Celery Worker:
```bash
docker logs <worker_container> | grep "max_bytes"
```

Должно быть:
```
📝 Splitting text into chunks (max_bytes=4500)...
✅ Text split into 2 chunks  # или 1 chunk
```
